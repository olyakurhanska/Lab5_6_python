# Лабораторні роботи №5–6

**Тема:** Проєктування інтерфейсу користувача з використанням шаблонів, форм та валідації даних у Django / Flask.

## Мета роботи

Навчитися створювати вебдодатки за допомогою Django та Flask, працювати з HTML-шаблонами, формами, серверною валідацією даних та CSRF-захистом.

## Опис проєкту

У ході лабораторних робіт було створено два вебдодатки «Каталог книг» із використанням Django та Flask.

Обидва додатки містять головну сторінку, список книг і форму для пропозиції нової книги.

## Виконані завдання

1. **Підготовка проєктів.** Створено Django- та Flask-проєкти, встановлено необхідні бібліотеки та налаштовано маршрути сторінок.

2. **Робота з HTML-шаблонами.** Реалізовано відображення інформації про книги за допомогою змінних, циклів, умов і фільтрів.

3. **Успадкування шаблонів.** Створено спільні шаблони `base.html`, навігаційне меню, підвал і CSS-оформлення сторінок.

4. **Форми у Django.** Створено форму для пропозиції книги з перевіркою назви, електронної пошти, жанру та опису. Реалізовано повідомлення про помилки та успішне надсилання.

5. **Форми у Flask.** Реалізовано аналогічну форму з використанням Flask-WTF, серверною валідацією та повідомленнями про результат.

6. **CSRF-захист.** Проведено перевірку захисту форм від запитів без CSRF-токена в обох додатках.

7. **Порівняння Django та Flask.** Проаналізовано структуру проєктів, особливості шаблонізаторів, форм, валідації та захисту даних.

## Запуск проєктів

Для запуску необхідно встановити Python та залежності з файлів `requirements.txt`.

### Django

Перейдіть у папку Django-проєкту та виконайте:

```powershell
cd django_project
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Після запуску сервер працюватиме за локальною адресою `http://127.0.0.1:8000/`.

### Flask

Перейдіть у папку Flask-проєкту та виконайте:

```powershell
cd flask_project
python -m pip install -r requirements.txt
python app.py
```

Після запуску сервер працюватиме за локальною адресою `http://127.0.0.1:5000/`.

Для роботи з формами Flask використовується секретний ключ `SECRET_KEY`. У проєкті передбачено тимчасовий ключ для локальної розробки.

**Примітка:** обидва додатки запускаються локально. Щоб переглянути їхню роботу, потрібно завантажити проєкт, встановити необхідні бібліотеки та запустити відповідний сервер. Адреси localhost не є публічними посиланнями.

## Результати роботи

У результаті створено два вебдодатки з аналогічною функціональністю. Реалізовано відображення каталогу книг, навігацію між сторінками, форми з перевіркою введених даних та повідомлення про успішне надсилання.

Під час порівняння встановлено, що Django-проєкт містить 18 Python та HTML-файлів, а Flask-проєкт — 6. Обсяг HTML-шаблонів становить 82 рядки у Django та 83 рядки у Flask.

## Висновок

Під час виконання лабораторних робіт було отримано практичні навички розробки вебдодатків із використанням Django та Flask.

Було вивчено створення HTML-шаблонів, успадкування сторінок, роботу з формами, серверну валідацію та CSRF-захист.

Django має більше вбудованих можливостей і підходить для складніших проєктів, тоді як Flask має простішу структуру та дозволяє швидше створювати невеликі вебдодатки.
